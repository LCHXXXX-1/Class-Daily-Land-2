核心功能

课堂上真正用得上的那几件事

所有功能都围绕"抬头一眼就知道现在该干什么"设计，不需要老师或学生额外操作。

🕒

灵动岛 · 课程倒计时

上课前按设定提前量亮起并进入倒计时，下课时弹提醒。 胶囊形态、呼吸动画与环形进度实时变化，全屏放 PPT 时自动收起， 下课或空白时段自动回到简略状态。

  • 提前提醒分钟数可调
  • 紧急预警条可压过课程文本强制显示
  • 系统时间偏移校准（±30 分钟）
📅

多课表与临时调课

建任意多张课表随时切换；某天临时换课直接用"临时调课"覆盖当天， 不动原课表。支持假期、调休补课与周末独立作息。

🙋

值日生与出勤

每日值日生按名单轮换，右键即可切换到上一位 / 下一位； 应到与实到人数随手改，面板上实时显示。

📚

作业滚动播报

按科目分组的作业清单在面板里自动平滑滚动，到顶到底自动停顿。 手指或鼠标一碰就暂停几秒，不跟你的操作抢画面。

🎨

主题与外观

跟随系统 / 浅色 / 深色三档主题，Windows 11 云母材质与圆角窗口。 面板宽度、字号、透明度、动画时长全部可调，也能一键调出设置中心。

🧩

插件市场

从内置市场发现、安装与更新插件，装完即可用，被禁用的插件不会加载。 插件可注册灵动岛文本、加长片段、预警条、下拉面板与独立设置页。

🖱️

触摸屏友好

所有滚动控件（含插件自带的与下拉列表）都支持手指拖拽与惯性滑动， 一体机、触摸大屏上直接上手。

🔔

托盘与自动更新

常驻系统托盘，右键菜单快速操作。启动时后台静默检查新版本， 也可随时手动检查，更新由独立启动器完成。

插件生态

自带三个，市场里还有更多

插件是标准的 Python 模块，通过插件 API 挂到灵动岛与设置页上；缺失的第三方依赖由宿主自动下载并校验安装。

⏰

时钟

class.lchxxxx-1.clock · v1.0.0

在灵动岛下拉面板里显示当前时间与日期，展开即见。

⛅

天气

class.hexwisp72.weather · v1.0.0

IP 定位 + Open-Meteo 数据，副岛上播放每种天气的专属动画，可在设置里预览。

🎵

媒体播放

class.hexwisp72.audio · v1.0.0

读取 Windows SMTC，把正在播放的歌名与歌手显示在主岛或副岛，停止后自动隐藏。

插件可以挂到这些位置

  • add_island_text()灵动岛文字
  • add_island_extra()主岛加长片段
  • add_island_banner()紧急预警条
  • add_subisland()副岛内容
  • add_panel()下拉面板
  • add_settings_page()独立设置页

开发者工具

做一个自己的插件

DeveloperTool 是给插件作者准备的独立 GUI：写代码、填元信息、打包成 .cblplugin，登录后直接上传到插件市场等审核。

  • GitHub Device Flow 登录，不用在工具里填密码
  • 一键打包成插件包，自动生成 plugin.json
  • 查看自己的上传记录与审核状态、驳回理由
  • 管理员可在工具内直接审核通过或驳回
  • 内置版本检查，工具自身也能更新
